# E-Commerce Website

An e-commerce web application I'm building as part of my React and full-stack web development learning journey.

## About the Project

This project is based on the SuperSimpleDev course and provides hands-on experience building an e-commerce application using React and JavaScript and integrating a course-provided backend.

Along the way, I've completed coding exercises, made my own changes, practiced debugging and used Git to track my development progress.

## Technologies

- React
- JavaScript
- HTML5 and CSS3
- Git and GitHub
- SuperSimpleDev course-provided backend
